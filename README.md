# Карта домов

Локальное приложение для телефона: список домов в стиле todo, адреса, ссылки, дата посещения, статус, неограниченные комментарии и фотографии хранятся в браузере через IndexedDB.

## Node.js backend с share-ссылкой

Можно запустить приложение как небольшой Node.js сервер:

```bash
npm start
```

По умолчанию сервер слушает `http://localhost:8099` и хранит проекты рядом с сервером в `data/projects/*.json`.

Во фронтенде доступны действия:

- `Сохранить` - создает или обновляет проект на сервере.
- `Ссылка` - копирует/открывает share-ссылку вида `?project=...`.
- `Загрузить` - загружает проект по текущей ссылке, ID проекта или полной share-ссылке и объединяет его с локальными записями.

Это простое файловое хранение без аккаунтов и прав доступа: любой, у кого есть ссылка, может загрузить и сохранить проект.

Синхронизация не заменяет локальные данные целиком. При одинаковом ID записи приложение объединяет данные: обычные поля берет из более свежей записи, а комментарии и фотографии объединяет отдельно по их ID. Удаления сохраняются как `deletedAt`, чтобы удаленный комментарий, фото или запись не возвращались со второго устройства при следующей загрузке.

## Как сделать, чтобы работало в поездке

Надежный вариант для мобильного браузера - установить приложение как PWA до поездки.

1. Разместить эту папку на HTTPS-адресе. Подойдет GitHub Pages, Netlify, Cloudflare Pages или любой статический хостинг.
2. Открыть этот HTTPS-адрес на телефоне.
3. Нажать `Установить` или в меню браузера выбрать `Добавить на главный экран`.
4. Открыть установленное приложение один раз и дождаться сообщения про офлайн-кэш.
5. Добавить тестовую запись с фото, закрыть интернет, открыть приложение снова и проверить запись.

После этого компьютер и сервер не нужны. Данные и фотографии остаются на телефоне в хранилище браузера/установленного PWA.

## Почему не через адрес компьютера

Адрес вроде `http://192.168.0.76:8099` удобен для разработки, но это не полноценный installable PWA: service worker обычно требует HTTPS. Поэтому такой вариант не гарантирует работу после отключения компьютера.

## Более жесткий вариант

Если нужно приложение, которое не зависит от браузерных правил PWA, следующий шаг - завернуть эту же страницу в Android-приложение через Capacitor. Тогда файлы будут внутри APK, а локальное хранилище останется на телефоне.
